# pairwise-rt-shadow-denoise

树叶投下的影子糊成一团，光追阴影只打一根光线，半影完全靠后期模糊猜；光源尺寸没参与采样，太阳和面光投出一样硬的边；时域累积用固定权重，移动物体后阴影拖出一条尾巴；空间降噪核按像素固定，近处阴影被抹平、远处仍然噪；深度不连续处没做拒绝，角色脚底和地面阴影粘在一起；alpha 测试的树叶写深度但没写不透明度，影子变成实心板；透明物体不投射阴影，玻璃后完全没有遮挡；接触硬化没做，物体贴地时影子应该更实；光源移动后历史权重没重置，影子追不上太阳；多光源叠加时每个光源各自降噪再相加，接缝处出现双重暗边。render/rt_shadow_denoise.py 是核心，tests/test_rt_shadow_denoise.py 15个红。要修的是：按光源尺寸采样；面光多采样；时域按运动自适应；空间核按世界尺度；深度不连续拒绝；alpha 测试保留镂空；透明按透射率投影；接触处提高权重；光源移动重置；多光源联合降噪。

## 运行

```bash
python -m pytest tests -q
```

初始状态：15 个用例失败。修复实现使全部用例通过，不要修改 `tests/` 下的测试。
